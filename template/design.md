# 作品集页面设计规范

本文档记录当前作品集页面的视觉基础，并为后续扩展按钮和导航栏提供一致的样式约定。颜色、字号和间距应优先复用现有 CSS 自定义属性与比例。

## 1. 配色

整体采用纯黑页面背景，以暖白文字保证阅读对比，再用珊瑚红作为少量强调色。卡片仍使用深绿灰表面色，与纯黑背景形成克制的层次对比。

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 主色 / 强调色 | `#E34660` | 视觉锚点、编号、强调文字、主要操作 |
| 主色悬停态 | `#C9344E` | 主要按钮悬停状态 |
| 辅助色 / 次级表面 | `#192725` | 项目卡片背景 |
| 辅助色 / 悬停表面 | `#1E302D` | 卡片悬停背景 |
| 预览底色 | `#10201D` | 项目预览图加载或留白区域 |
| 页面背景 | `#000000` | 页面及浏览器主题底色，纯黑，不叠加渐变 |
| 主文字 | `#F2F5F3` | 页面标题、卡片标题 |
| 次级文字 | `#9BAAA6` | 正文、描述 |
| 弱化文字 | `#72827E` | 页脚等低优先级信息 |
| 强调浅文字 | `#F08091` | 标签文字 |
| 默认边框 | `rgba(185, 211, 204, 0.09)` | 卡片等深色表面的细边框 |
| 强调边框 | `rgba(227, 70, 96, 0.38)` | 卡片悬停边框 |

页面背景保持纯黑，不添加绿色或其他颜色的渐变；装饰性红色光晕仅用于小型强调元素，保持低不透明度，不应影响正文可读性。

## 2. 字体

- **字体栈**：`Inter, "PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif`。
- **正文基准**：浏览器根字号 `16px`；常规行高 `1.6`，正文颜色使用次级文字色。
- **主标题**：桌面端随视口在 `32–51.2px` 之间响应变化（`clamp(2rem, 5vw, 3.2rem)`）；字重 `700`，行高 `1.2`，字距 `-0.045em`。
- **介绍文案**：约 `15.4–17.6px`（`clamp(0.96rem, 2vw, 1.1rem)`），常规字重，行高 `1.8`。
- **卡片标题**：约 `17.9px`（`1.12rem`），字重 `650`，字距 `-0.02em`。
- **卡片正文**：约 `14.1px`（`0.88rem`），常规字重，行高 `1.7`。
- **眉题 / 类别标签**：眉题约 `12.2px`、字重 `700`、字距 `0.16em`；类别标签约 `11.5px`、字重 `600`。
- **编号**：约 `12.5px`，字重 `700`，使用等宽数字特性（`font-variant-numeric: tabular-nums`）。

标题与正文主要通过字号、字重、颜色和留白建立层级；避免给所有文本都使用强调色或粗体。

## 3. 间距与布局

以 `4px` 为基础节奏，常用取值为 `8 / 10 / 12 / 14 / 16 / 18 / 20 / 22 / 32 / 42 / 52 / 58px`。

| 场景 | 桌面端 | 中等屏幕（≤820px） | 手机（≤560px） |
| --- | --- | --- | --- |
| 页面最大内容宽度 | `1080px` | `700px` | `420px` |
| 页面左右留白 | 至少 `24px` | `20px` | `16px` |
| 页面顶部留白 | `76px` | `60px` | `48px` |
| 介绍区与作品网格间距 | `58px` | `42px` | `32px` |
| 卡片网格列数 | 3 列 | 2 列 | 1 列 |
| 卡片网格间距 | `20px` | `16px` | `14px` |
| 卡片内容内边距 | `19px 20px 21px` | 同桌面 | `16px 17px 18px` |
| 卡片标题与标签间距 | `10px` | 同桌面 | 同桌面 |
| 标签与描述间距 | `12px` | 同桌面 | 同桌面 |
| 网格与页脚间距 | `52px` | 同桌面 | `34px` |

布局应保持呼吸感。小屏幕时优先缩减外围和模块间距，并将项目卡片改为单列，不压缩文字行高。

## 4. 组件样式

### 卡片

- 默认背景 `#192725`，`1px` 细边框 `rgba(185, 211, 204, 0.09)`，圆角 `18px`。
- 默认不加明显投影；悬停时背景改为 `#1E302D`，边框改为 `rgba(227, 70, 96, 0.38)`。
- 悬停上移 `5px`，投影为 `0 18px 42px rgba(0, 0, 0, 0.2)`；过渡时长 `180ms`。
- 卡片预览图使用固定宽高比裁切填充；桌面比例 `1.56`，手机比例 `1.65`。
- 键盘焦点使用 `2px` 主色外框，外移 `4px`，不可仅依靠悬停提示交互状态。

### 按钮（后续新增时遵循）

当前作品集页面没有独立按钮。新增主要操作按钮时，建议采用主色 `#E34660` 实底、主文字色文字、`12px` 圆角、`10px 18px` 内边距；悬停切换为 `#C9344E`。使用 `1px` 强调色焦点外框，避免默认厚重投影。次要按钮使用透明底、默认边框与浅色文字，悬停时可使用卡片悬停表面色。

### 导航栏（后续新增时遵循）

当前页面没有导航栏。若需要增加，建议保持简洁低调：透明或 `#192725` 表面、底部 `1px` 默认边框、`14px` 圆角；导航项采用 `8px 12px` 内边距、次级文字色。当前项或悬停项使用主色文字或淡主色背景（`rgba(227, 70, 96, 0.1)`），不使用强投影，避免与页面标题争夺视觉焦点。

### 标签与装饰

- 类别标签使用淡主色背景 `rgba(227, 70, 96, 0.1)`、边框 `rgba(227, 70, 96, 0.2)`、文字 `#F08091`，胶囊圆角 `999px`。
- 页头圆点使用主色，尺寸 `16px`；窄屏缩为 `13px`。轻微光晕可使用 `0 0 26px rgba(227, 70, 96, 0.28)`。
- 小型圆形图标按钮使用 `36px` 直径、`1px` 半透明白边框、圆形裁切。

## 5. 动效与无障碍

- 默认交互过渡为 `180ms ease`；图片缩放过渡为 `350ms ease`。
- 悬停效果用于提示交互，不改变内容顺序或导致布局跳动。
- 遵循 `prefers-reduced-motion: reduce`，减少或关闭非必要动效。
- 保持可见焦点指示、足够的文字对比度，并为内容图片提供准确的替代文本。
